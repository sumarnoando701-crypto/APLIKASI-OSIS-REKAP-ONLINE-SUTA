1. Edit capacitor.config.json: ganti server.url dengan alamat server rumah (disarankan https).
2. Buat repo GitHub baru, unggah seluruh isi folder ini (branch main).
3. Tab Actions > Build APK > tunggu selesai > unduh artifact "osis-absensi-apk" (app-debug.apk).
4. Pasang APK di ponsel, buka, izinkan notifikasi.
Server (folder osis-absensi) tetap harus berjalan 24 jam di rumah.
